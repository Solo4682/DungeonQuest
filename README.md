# DungeonQuest

My game which is inspired from Dungeons And Dragons

This game was created with a spur of inspiration to updates will take time. Kindly Understand that I'm also a beginner and am trying my level best to update the game. Any recommendations are gladly accepted.

The current project runs on CSS, JavaScript and HTML files so as to ensure that the players can play the game on any web-browser instead of needing to download code files.

About the Game :

DungeonQuest is a a dark fantasy, story driven RPG where every choice has consequences, knowledge is earned, and survival is of the fittest. The journey starts in Dunmere  where a church bell rings for 13 times and something beneath the village answers to it.

Current updates until now : Initialization of the story.
                            Character creation Scene.
                            Basic combat Scene interface.
                            Initial player and enemy combat systems.
                            Attack, defend, flee, recover, healing potion and observe options added to the fight interface
                            Enemy behaviors and gradual gaining of knowledge as story progresses by finding the hints.

To run the project Locally : VS Code
                             Live Server extension for VS code


Clone the Git repository using : git clone https://github.com/Solo4682/DungeonQuest.git . Open the project folder in VS Code and start the index.html file with Live Server, a local url should open up in your default broswer

To play in web visit the website : https://dunmere.netlify.app/

The current game interface might look plane, dull and boring but to understand the game kindly read the text displayed on the screen instead of just clicking the buttons randomly.
